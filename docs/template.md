# 章节模板

本文件是全书章节的写作骨架。共两套模板：

- **完整模板（19 节）** — 适用于 **Part 2 起**、有“六门语言各自实现”对象的概念章（变量、函数、类、GC……）。
- **Part 1 概念章模板（变体）** — 适用于 **Part 1** 等叙述/原理型章节（发展史、编译器、解释器、虚拟机、运行时、类型系统），去掉逐语言代码节。

> 遵守项目单文档单语言规范：中文章节用中文标题，英文章节（`.en-US.md`）用英文标题。下面以中文为例。

---

# 一、完整模板（19 节 · Part 2 起）

```markdown
# 第 NN 章 · 标题

**简体中文** ｜ [English](./NN-slug.en-US.md)

---

## 1. 学习目标
本章结束后，你将能够……

## 2. 为什么会出现这个概念
历史背景、解决什么问题、如果没有它会怎么样。

## 3. 底层原理
计算机内部发生了什么：内存、CPU、Runtime、实现方式。

## 4. JavaScript
语法 · 示例 · 注意事项

## 5. Python
语法 · 示例 · 注意事项

## 6. Java
语法 · 示例 · 注意事项

## 7. C++
语法 · 示例 · 注意事项

## 8. C#
语法 · 示例 · 注意事项

## 9. SQL（如相关）
SQL 实现 / 在数据库中的体现

## 10. 五语言横向对比
| JavaScript | Python | Java | C++ | C# |
|------------|--------|------|-----|-----|
共同点 · 区别 · 适用场景

## 11. 底层实现对比
V8 · CPython · JVM · Native · CLR

## 12. 性能分析
时间复杂度 · 空间复杂度 · Runtime 成本

## 13. 工程实践
真实项目怎么写 · 推荐方案 · 不推荐方案

## 14. 最佳实践
推荐写法 · 命名 · 代码风格 · 设计原则

## 15. 常见坑
新人最容易犯的错误 · 为什么错 · 如何避免（至少 5 个）

## 16. 面试题
基础 · 中级 · 高级

## 17. 练习
基础 · 提高 · 挑战

## 18. 本章总结
一句话总结 · 核心知识点 · 检查清单 · 下一章预告

## 19. 延伸阅读
经过验证、当前可访问的参考资料（遵守 CONTRIBUTING 的延伸阅读规范：没有可访问链接就不列，严禁编造）。
```

# 二、Part 1 概念章模板（变体）

> 适用于 Part 1 等**叙述 / 原理型**章节——这类主题没有"六门语言各写一遍"的对象，因此去掉逐语言代码节，聚焦"为什么、历史、原理、对本书六门语言的意义"。

```markdown
# 第 NN 章 · 标题

**简体中文** ｜ [English](./NN-slug.en-US.md)

---

## 1. 学习目标
本章结束后，你将能够……

## 2. 为什么会出现（核心问题）
用一句话点出本章要回答的那个"为什么"，再展开动机。

## 3. 历史脉络
时间线 + 每一步"解决了上一步的什么痛点"（配 Mermaid 图）。

## 4. 它到底是什么 · 底层主线
把概念压成一条主线；触及底层机制，但不陷入某一门语言的语法。

## 5. 关键概念与术语
本章引入的核心术语（与 CONTRIBUTING 术语表保持一致）。

## 6. 在本书六门语言中的体现
用一张表/一段话，把 JavaScript / Python / Java / C++ / C# / SQL 放回本章脉络。

## 7. 常见误解
围绕本主题、读者普遍存在的错误认知，逐条澄清。

## 8. 思考题
2–4 个开放式问题，引导读者自己推演。

## 9. 本章小结
一句话总结 · 检查清单 · 下一章预告

## 10. 延伸阅读
经典、稳定的参考资料。
```
